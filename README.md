# 簡易POS（試作）

簡易WMSの派生。スマホのカメラ（またはBluetoothスキャナ）でバーコードを読み、レジ（カート・値引・税計算・お会計・お釣り）、売上の記録、返品・取消、日別の精算、**インボイス（適格簡易請求書）のレシート**まで行える簡易POSです。画面は単一のHTML、GASは倉庫（JSONの受け口）、データはGoogleスプレッドシートです。

- 画面: [`index.html`](index.html)（単一ファイル。ZXing-jsで読み取り。ホーム画面に追加してPWAとしても使える）
- 倉庫: [`gas/Code.gs`](gas/Code.gs)（スプレッドシート5枚: 商品マスタ／入出荷履歴／売上明細／取引／設定）
- 設計: [`docs/01_設計メモ.md`](docs/01_設計メモ.md)／手順: [`docs/02_手順メモ.md`](docs/02_手順メモ.md)

**状態: 試作。PCブラウザと単体テストで確認済み。iPhone実機・GASの本番デプロイでの確認はこれから。実際の店舗のレジとして使う前に、実機での確認と、税務・会計の専門家への確認（インボイス・電子帳簿など）が必要です。**

## 要点
- 単価は税込。税率は10%と軽減8%。消費税額（内税）は、税率ごとの合計から、1枚のレシートにつき税率ごとに1回だけ端数処理（国税庁Q&A 問57）
- 取消・返品は、元の取引を書き換えず、マイナスの取引を足す（赤黒）
- 会計の二重送信は、識別子で防ぐ
- 登録番号は、事業者が自分の番号を設定する（未設定のレシートは適格簡易請求書にならない）
- 個人情報は持たない

## 会計ソフト向けの日別CSV（v0.3）
精算タブから、期間を選んで「日別の売上CSV」を書き出せます（1日1行。純売上・税率別の税込／内消費税等／税抜・支払方法別。特定の会計ソフトの形式ではない汎用の形）。仕訳の科目・税区分や、申告に使う税額は決めません。詳しくは `docs/01_設計メモ.md` の9章。

## アーカイブ（v0.2）
「アーカイブ」タブから、古い取引・売上明細・入出荷履歴を、年ごとの別スプレッドシートへ移せます（コピー→行数確認→元から削除。移した取引は、見る・再発行・精算はできますが、返品・取消はできません）。詳しくは `docs/01_設計メモ.md` の8章。

## セキュリティ
合言葉（APP_TOKEN）は、GASのスクリプトプロパティだけに置き、16文字以上にします。スプレッドシートの共有は「制限付き」にしてください。このリポジトリには、合言葉・スプレッドシートID・GASのURLは入れません。

## テスト
```
cd test && npm i && cd ..
node --test test/*.test.js
```
GASのコード（`gas/Code.gs`）を、メモリ上の模擬スプレッドシートで動かして検証します。画面の動作確認は `node test/dev-server.js`。
