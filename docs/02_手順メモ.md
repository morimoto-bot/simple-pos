# 簡易POS 手順メモ（v0.2.0）

## 1. 置いてあるもの
| もの | 場所 |
|---|---|
| 画面（単一HTML） | `index.html`（GitHub Pages などHTTPSで配信する。カメラはHTTPSでしか使えない） |
| GAS（倉庫の受け口） | `gas/Code.gs`（自分のGoogleアカウントでスクリプトを作って貼る。`CONFIG.SPREADSHEET_ID` に自分のスプレッドシートのIDを入れる。空のままだと、スクリプトに紐づいたシートを使う） |
| スプレッドシート | 自分のGoogleスプレッドシート（見出しは、最初の通信で自動で作られる。WMSとは別のブックにする） |
| 設計メモ | `docs/01_設計メモ.md` |

## 2. GASをデプロイする（所要10分。WMSと同じ手順）
1. スクリプトエディタを開く → 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に、**`APP_TOKEN`＝16文字以上のランダムな文字列**を追加する（WMSの合言葉とは別のものにする。コードやシートには書かない）
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」→ **次のユーザーとして実行＝自分／アクセスできるユーザー＝全員** → デプロイ。最初の1回は、スプレッドシートへのアクセスの許可を求められる
3. 出てきた `/exec` のURLを控える（合言葉とは別に管理する）
4. `?action=ping` を付けて開き、`{"ok":true,"app":"simple-pos",…}` が出ることを確認（合言葉が違います、はURLだけ開いた時の正常な表示）
5. コードを更新したときは、「デプロイを管理」→ 鉛筆 → バージョン「新しいバージョン」→ デプロイ（URLは変わらない）

## 3. 画面を開いて設定する
1. 画面のURLを開く（iPhoneはSafariで開き、「ホーム画面に追加」するとアプリのように使える）
2. 右上の ⚙ → GASのURLと合言葉を**手入力**する → 「接続テスト」で OK を確認
3. 商品タブで、商品を登録する（バーコードを読んで登録、またはCSVの取り込み。`JAN,商品名,単価（税込）[,税率区分[,在庫]]`）
4. **インボイス**: ⚙ の「インボイスの設定」に、事業者名と、**自分の登録番号（T＋13桁）**を入れて保存する。登録番号が空のままだと、レシートは適格簡易請求書にならない（「登録番号が未設定です」と出る）。端数処理は、切り捨て／切り上げ／四捨五入から選ぶ（1枚のレシートにつき、税率ごとに1回）

## 4. 使い方（要点）
- **レジ**: 商品ボタンかバーコードでカートへ → 必要なら「値引」（単品／小計。円・％）→「お会計へ」→ 支払方法・預り金（お釣りが出る）・客数 →「会計を確定」→ レシート（印刷・PDF保存）
- **未登録商品**: マスタに無いバーコードを読むと、「未登録商品として売る」か「商品として登録」を選べる。売る場合は、その場の金額・数量・税率を入れる（在庫は動かない）
- **取引**: 日付を選び、取引を開く → 再発行／返品（行と数量を選ぶ）／取消（全体）。取消・返品は、マイナスの取引が足される（元は消えない）。現金の取引は、返金してから操作する
- **精算**: 日付を選ぶと、純売上・件数・客数・支払方法別・税率別が出る。現金の売上は、レジの現金と照らし合わせる額
- **入荷／棚卸**: バーコードを読んで数え、確定する（棚卸は、数えた商品の差異だけ直す）
- 通信が遅くて「会計を確定」を二度押しても、二重には記録されない

## 5. 運用上の注意
- **スプレッドシートの行は、手で書き換えない**（特に取引・売上明細。売上の記録が壊れる）。直したいときは、取引タブから返品・取消をする
- スプレッドシートの共有は「制限付き」（自分だけ）にする。合言葉とGASのURLは、公開しない
- 取引・返品・取消・精算は、直近3,000件（売上明細は直近20,000行）を見る。年単位で使うときは、古い行を別のシートへ移す（移動だけ）
- 決済サービス（クレジットなど）を使った取引を取り消したときは、**サービス側でも取消が必要**な場合がある
- 試作です。実際の店舗のレジに使う前に、実機での確認と、税務・会計の専門家への確認（インボイス、電子帳簿など）をしてください

## 8. アーカイブ（v0.2。データが増えた時の備え）
「アーカイブ」タブで、設定・確認・実行・閲覧ができます。
- **移す対象**: 取引（と売上明細）は、日時から決めた日数（30・60・90・120・180・365日。既定90日）が過ぎたもの。入出荷履歴は、直近の数か月（2・3・6・12か月。既定2か月）だけ残して、古い月を移します
- **移した先**: 「簡易POS_アーカイブ_2026」のように年ごとのスプレッドシート（初回に自動で作成。マイドライブ直下。好きなフォルダへ移してよく、**削除・共有解除はしない**）。シート名は「取引_2026-10」のように月ごと
- **安全**: 「コピー→行数の確認→元から削除」の順。行数が合わなければ、元は消さずに止まります。途中で止まっても、再実行で重複しません
- **移した取引**: 見る・レシートの再発行・精算の集計はできます。**返品・取消はできません**（返品を受け付ける期間より短い日数にしないでください）。CSVの書き出しは、いまのシートの分だけです
- **実行のしかた**: 「対象を確認」で件数を見る（何も動かない）→「今すぐ実行」。慣れたら「自動で実行する」をON（1日1回、最初の通信）。データが多い時は、GASの時間トリガー（夜など）に `archiveDaily` を登録（GASエディタ左の「トリガー」→「トリガーを追加」→ 関数 `archiveDaily`・「日付ベース」）
- 取引が多い店（90日で3,000件を超える）は、日数を短くするか、`CONFIG.TX_WINDOW` を増やしてください（返品・取消が探すのは、取引シートの直近3,000件までです）
